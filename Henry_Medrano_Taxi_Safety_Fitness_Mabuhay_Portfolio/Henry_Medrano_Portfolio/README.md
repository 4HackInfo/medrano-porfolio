# Henry Medrano Portfolio

A responsive, single-page portfolio concept for Henry Medrano, featuring **Taxi Safety, Fitness Life, Mabuhay System**.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — unique dark teal, yellow, and green responsive layout
- `script.js` — mobile navigation
- `assets/henry-profile-illustration.jpg` — illustrative placeholder portrait
- `assets/portfolio-concept-preview.png` — generated visual concept reference

## Preview
Extract the ZIP and open `index.html` in a modern browser.

## Personalize before publishing
The portrait is an AI-generated illustration and is **not a verified photo of Henry**. Replace `assets/henry-profile-illustration.jpg` with Henry's actual photo if desired. Update the skills, email, links, and project features to reflect verified details. The project content is presented as a concept; revise it to match the actual system.

## Publish
Upload the extracted files to a static host such as GitHub Pages, Netlify, or any web server. Keep the `assets` folder beside `index.html`.
